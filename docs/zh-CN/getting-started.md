# 快速开始

Web 版 FairyGUI 预览器：在浏览器中加载并预览 FairyGUI 导出的 UI 包。

## 环境要求

- 现代桌面浏览器（Chrome / Edge / Firefox 最近两个大版本）
- 无需安装 Unity 或 FairyGUI 编辑器即可预览

## 安装

项目处于初始阶段，安装与运行方式随首个版本发布在此处更新。

## 验证

首个版本发布后，此处将提供最小验证步骤（打开页面并加载一个 FairyGUI 导出包）。

## 首次运行

待首个版本落地后补充：最小可运行示例与预期输出。
